# Аня & Никита — 10.10.2026

Мобильный свадебный сайт: один экран за другим, отсчёт до торжества,
программа дня, галерея, место проведения, дресс-код и анкета гостя
с кнопками «Иду / Не иду».

Готовое к публикации приложение без сборки: только HTML, CSS и JS.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Весь текст сайта: имена, дата, программа, адрес, телефоны |
| `styles.css` | Оформление, палитра, анимации |
| `app.js` | Отсчёт, меню, галерея, логика анкеты |
| `assets/` | Картинки галереи и иконка сайта |
| `tools/gen-assets.js` | Генератор картинок-заглушек (запускать необязательно) |

## Как посмотреть локально

Откройте `index.html` в браузере. Для проверки на телефоне удобнее
локальный сервер:

```powershell
python -m http.server 8080
```

и затем на телефоне в той же сети Wi-Fi: `http://<IP-компьютера>:8080`

## Что заменить на своё

1. **Тексты** — `index.html` (ищите комментарии в разделе каждой секции).
2. **Адрес и карту** — секция `#place`: адрес и ссылку на Яндекс.Карты.
3. **Телефоны** — секция `#contacts`.
4. **Фото** — положите свои снимки в `assets` с именами
   `photo-1.svg … photo-6.svg` (или поменяйте имена в `index.html`).
5. **Дата** — `app.js`, `CONFIG.weddingDate` (сейчас `2026-10-10T15:00:00`).

## Как получить ссылку для гостей

Сайт статический, поэтому подойдёт любой бесплатный хостинг:

- **GitHub Pages** — залейте папку в репозиторий, включите Pages →
  ссылка вида `https://логин.github.io/репозиторий/`
- **Netlify Drop** (netlify.com/drop) — просто перетащите папку в окно,
  ссылка появится сразу
- **Vercel / Cloudflare Pages** — то же самое, с подключением домена

## Чтобы ответы гостей приходили вам (необязательно)

Сейчас ответ сохраняется в браузере гостя и показывается благодарностью.
Чтобы получать ответы в Telegram:

1. Создайте бота у `@BotFather` и скопируйте токен.
2. Напишите своему боту любое сообщение и узнайте `chat_id`
   через `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. В `app.js` впишите:

```js
telegram: {
  botToken: '123456789:AAE...',
  chatId: '-1001234567890'
}
```

После этого каждый ответ будет приходить сообщением в Telegram.
